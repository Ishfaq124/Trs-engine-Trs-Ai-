# Research Questions

## RQ1 — Self-model stability
Can evidence-linked revision preserve continuity while still allowing capability
beliefs to change under repeated counterevidence?

## RQ2 — Bounded workspace
Does limiting globally broadcast content improve consistency or reduce irrelevant
memory intrusion relative to a full-context baseline?

## RQ3 — Temporal lineage
Can TRS ancestry explain belief changes better than a plain transcript?

## RQ4 — Contradiction handling
Does explicit contradiction pressure improve correction accuracy?

## RQ5 — Multi-timescale consolidation
Do fast, session, and slow consolidation layers preserve useful information
better than a single summary-memory layer?

## RQ6 — Consciousness-related indicators
Which proposed computational indicators can be operationalized and measured
without treating self-report as evidence of subjective experience?
