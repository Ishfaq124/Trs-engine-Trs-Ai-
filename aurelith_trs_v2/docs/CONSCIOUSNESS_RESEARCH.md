# Consciousness Research Position

## What this project claims

Aurelith/TRS implements mechanisms that can be evaluated against computational
indicator properties discussed in scientific theories of consciousness.

## What it does not claim

The repository does not assert that:

- Aurelith has phenomenal experience.
- a language model is conscious.
- persistent memory proves consciousness.
- self-report proves consciousness.
- a global workspace by itself proves consciousness.

## Experimental questions

1. Does information compete for a bounded global workspace?
2. Does globally selected content influence otherwise separate modules?
3. Can the system represent beliefs about its own beliefs?
4. Does it maintain a temporally coherent self-representation?
5. Can it revise self-representations under counterevidence?
6. Can it predict consequences before acting?
7. Is uncertainty calibrated against later outcomes?
8. Does recurrent processing improve behavior over feed-forward baselines?

Candidate research families include recurrent processing, global workspace,
higher-order theories, predictive processing, and attention-schema theory.
