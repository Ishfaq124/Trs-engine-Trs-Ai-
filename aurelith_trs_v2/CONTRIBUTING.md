# Contributing

Aurelith/TRS is a research project. Prefer measurable, reproducible mechanisms
over anthropomorphic claims.

A useful contribution should answer at least one of:

- What hypothesis does this change test?
- What state or behavior does it make measurable?
- What baseline does it compare against?
- What failure mode does it expose?
- What evidence would falsify the claim?

Do not submit changes whose main purpose is to make Aurelith claim that it is
conscious, alive, or sentient.
